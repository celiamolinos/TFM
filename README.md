El archivo preprocesamiento datasets contiene la limpieza y preprocesamiento de los datos utilizados en el estudio. Este genera los archivos flu_esp_index, malaria_esp_index, nilo_it_index. A partir de estos archivos se definen los notebooks Flu ventana 12, malaria ventana deslizante 12 y nilo ventana deslizante 12 con extensión .ipynb. Estos continen las diferentes arquitecturas diseñadas para la predicción de los brotes de enfermedades infecciosas. El archivo ejecuciones contiene los valores de R^2 obtenidos para cada modelo segun la arquitectura utilizada para cada entrenamiento.
